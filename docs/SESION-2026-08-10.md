## Estado de la Nexys A7 al finalizar

| Componente | Estado |
|---|---|
| FPGA bitstream | En flash SPI (persistente). Arranca solo. |
| Firmware ROV | NO persistente. Requiere upload UART cada power-cycle. |
| UART CLI | 115200 8N1. Todos los comandos funcionales. |
| CFS / ROV | Funcionando: armed, heartbeat, depth, IMU, encoders, PID, mixer |
| PWM | 8 canales servo/ESC por PMOD JA |
| Encoders | 8 canales por PMOD JD/JC |
| SPI | PMOD JB (no conectado a flash onboard) |
| I2C | PMOD JC |
| JTAG OCD | Pines de 7-segment, debug habilitado |
| Ethernet | PHY LAN8720A conectado pero sin usar en el diseño actual |

## Al encender la Nexys

1. La FPGA carga el bitstream desde flash automáticamente
2. El bootloader NEORV32 aparece en UART (115200)
3. Subir firmware: `cmake --build --preset debug --target upload` (o manual `u` + binario + `e`)
4. El firmware ROV está operativo
